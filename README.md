# Теория углов в теннисе

Интерактивная схема корта: перетаскиваешь соперника — приложение показывает крайние углы удара и рекомендуемую позицию игрока (биссектриса). Режимы «Розыгрыш» и «Подача».

Чистый HTML/JS, без зависимостей и сборки.

## Запуск
- Веб: GitHub Pages (Settings → Pages → Branch: main, папка /root).
- iPhone: открыть ссылку в Safari → Поделиться → «На экран «Домой»».
- Telegram: @BotFather → /newapp (или Menu Button) → указать HTTPS-ссылку на Pages.
